`incidence_moments` takes a `substeps` keyword, for the single- and multi-type methods. It runs the recursion on a grid of that many sub-steps per step and adds up the sub-step counts within each observed step, so the shape of the result is unchanged. This captures that an infectee in the same step as its infector is later in that step, which matters when the generation time is short compared with a step. The default of 1 keeps the current results.
