A `CapacityConstrained` budget is now shared by every group in every engine unless it is a `PerGroup`. Previously `simulate_by_generation` gave each type the whole `budget_per_period`, and a `GroupVaccination` with `group_key = :type` did the same in the individual-based simulation. Both now draw on one pool, which `simulate_by_generation` splits between types by population. A budget per type is written `PerGroup(1 => ..., 2 => ...)`. The engines that read a campaign without simulating individuals (`simulate_by_generation`, the mixing approximations and `HybridProcess`) now refuse, in the same words, an intervention they cannot apply. `simulate_by_generation` also refuses `on_refusal = DeferRefused()`, which it used to ignore.
