`Isolation` takes a `trigger`, which sets what the isolation delay is counted from. `AfterSymptomOnset()` is the default and keeps the current behaviour. `AfterPositiveTest()` isolates a case whose `:test_result` is positive. The isolation time is the `:test_time` that `Testing` records plus the delay, which then stands for the turnaround. Paired with `eligibility = AllCases()`, it also isolates cases without symptoms. To add a trigger, subtype `IsolationTrigger` and define a method of `isolation_reference_time`.
