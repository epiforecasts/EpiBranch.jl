`clinical_presentation` now draws an incubation period for every case and stores it as `:latent_incubation_period`, whether or not symptoms occur. `:incubation_period` and `:onset_time` stay `NaN` for asymptomatic cases. `incubation_linked_generation_time` centres each case on its onset-based incubation period where there is an onset, and otherwise on the latent draw. Asymptomatic infectors no longer fall back to a fixed 5-day centre. A case with no incubation period at all, for example one built without `clinical_presentation`, raises an `ArgumentError`. An asymptomatic case consumes one more random draw, which changes the realisations of seeded runs with `prob_asymptomatic > 0`.
