`simulate` runs a branching process with a discrete generation time on whole days, and nothing about individuals feeding back on transmission, as daily counts when the run is bounded by `max_time` alone (`max_cases = nothing`, `max_generations = nothing`). The result is a `CountSimulationState`, an `AbstractSimulationState` that builds its people, and so its line list, when they are first asked for, from a random number stream it holds. `simulate(model, state; max_time)` continues it. A `Poisson` or negative binomial offspring law and `RenewalOffspring` with a vector generation time qualify; `EpiBranch.count_rule` is the seam by which another model opts in.
