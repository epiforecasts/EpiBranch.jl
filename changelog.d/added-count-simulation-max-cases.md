The count-level path runs a bounded run too: `simulate` with `max_generations = nothing` and a `max_cases` (with or without `max_time`) stops at the end of the first day on which the total reaches the cap, so it can hold more cases than that. `containment_probability(model, n; max_cases, max_generations = nothing)` uses it for a model that qualifies, and gives the same event as the individual simulation. A run with `max_generations` is still simulated as individuals.
