`incubation_linked_generation_time` no longer has a fixed spread of 2 days. Its `omega` argument is replaced by `relative_spread`, the spread as a fraction of each case's incubation period (default 0.5). The skew is now chosen for the distribution truncated at zero, so the share of transmission before onset equals `presymptomatic_fraction` for short incubation periods as well as long ones. Generation times drawn with the default settings change, and code passing `omega` must switch to `relative_spread`.
