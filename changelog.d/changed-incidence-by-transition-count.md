`weekly_incidence`, `incidence`, `epicurve` and `end_of_outbreak_inputs` now take `by` as a `TransitionCount` naming the state that places a case, such as `by = TransitionCount(:reporting)`, in place of a `Symbol`. The default is `TransitionCount(:onset)`, which still places a case without an onset by its infection time. `by = :infection` is now `TransitionCount(:infection)`, and any other recorded time `:x_time` is now `TransitionCount(:x)`.
