`Isolation` takes a `trigger`, which sets the event the isolation delay is counted from. `AfterSymptomOnset()` is the default and keeps the current behaviour. `AfterPositiveTest(name = :test)` isolates a case whose `:<name>_result` is positive. With several `Testing` steps in a model, `name` picks the one that starts isolation. The isolation time is the `:<name>_time` that `Testing` records plus the delay, and the delay then stands for the turnaround. Paired with `eligibility = AllCases()`, it also isolates cases without symptoms. To add a trigger, subtype `IsolationTrigger` and define a method of `isolation_reference_time`.
