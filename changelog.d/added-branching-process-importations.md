`BranchingProcess` takes an `importations` keyword: a vector of times at which further index cases arrive, in addition to the `n_initial` cases at time 0. Each import is an individual with its own infection time and `:infection_route = :external`, and capacity limits, `max_cases` and other stopping rules, `max_time` and population depletion apply to it as to any other case. In a multi-type model each import's type is drawn uniformly from the types. Only `BranchingProcess` reads `importations`.
