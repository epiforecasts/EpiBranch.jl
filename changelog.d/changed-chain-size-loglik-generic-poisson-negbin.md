`loglikelihood(::ChainSizes, ::Poisson)` and `loglikelihood(::ChainSizes, ::NegativeBinomial)` now use the generic method through `chain_size_distribution` instead of two single-seed fast paths that gave the same values. Results are unchanged, except that `Poisson(0)` now throws an `ArgumentError`, as `Borel(0)` does, instead of returning `NaN`.
