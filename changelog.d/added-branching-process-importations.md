`BranchingProcess` takes an `importations` keyword: a vector of times at which further index cases arrive, in addition to the `n_initial` cases at time 0. Each import is an individual with its own infection time and `:infection_route = :external`. Capacity limits (`max_cases`), other stopping rules (`max_time`) and population depletion apply to imports as to any other case. In a multi-type model the type of each import is drawn uniformly from the types. Only `BranchingProcess` reads `importations`.
