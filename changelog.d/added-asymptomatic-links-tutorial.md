A tutorial, "Asymptomatic cases and how symptoms link to infectiousness", states each link between symptoms, infectiousness and a within-host trajectory as a short model built from the existing seams: a proportion asymptomatic with nothing linked, lower infectiousness, more contacts, a shorter infectious period, an onset-linked generation time with its own timing for asymptomatic cases, and a trajectory that drives onset, infectiousness or both. The `clinical_presentation` docstring says which keys a replacement builder sets.
