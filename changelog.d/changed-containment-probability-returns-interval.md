**Breaking:** `containment_probability` now returns `(; n_contained, n, proportion, mcse, posterior)`, with the Monte Carlo standard error `sqrt(p * (1 - p) / n)` and a `Beta(n_contained + 0.5, n - n_contained + 0.5)` posterior for the underlying probability (the Jeffreys prior `Beta(0.5, 0.5)` updated with the runs), in place of a bare proportion. Use `.proportion` for the previous value. `scenario_sweep` still reports the proportion in its `containment_probability` column. The new `containment_difference(a, b; paired)` gives the difference in containment between two sets of runs with its Monte Carlo standard error, for paired runs (`paired = true`, sharing random numbers) or independent ones. `containment_difference(model_a, model_b, n; paired, kwargs...)` simulates from two models and keeps only whether each run was contained, as `containment_probability(model, n)` does; with `paired = true` both run from the same `CommonRandomNumbers` seed.
