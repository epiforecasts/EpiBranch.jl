Reverse-mode gradients now work through the model constructors and likelihood wrappers, as in `loglikelihood(ChainSizes(sizes), BranchingProcess(Poisson(R)))`, `chain_size_distribution`, `chain_length_distribution` and `offspring_distribution`. Mooncake no longer stops at building a model, and Enzyme no longer fails to compile the chain-size likelihood or returns a wrong gradient for a loop over `chain_size_distribution`. Both are loaded through new `Mooncake` and `Enzyme` package extensions. A bare model's `progression` is now the empty tuple, so the compiler can see that no reporting step thins the chain-size law. A likelihood estimated by simulation raises an error under Enzyme in reverse mode, and Enzyme does not yet differentiate the closed-form likelihood of a `ModelSpec`.
