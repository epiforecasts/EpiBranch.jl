`simulate` runs a branching process with a `Binomial` or `Geometric` offspring law on the count-level path, with a finite `Population`, and with several types when every type has such a law. Each member draws its offspring number when infected, and the offspring are placed on later days by the generation time. The rule is an `OffspringCountRule`. The time and memory of the path grow with the number of cases for these laws.
