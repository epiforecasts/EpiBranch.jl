A new docs page, "Coming from simulist, epichains, ringbp and superspreading", maps the functions and arguments of each of those packages to the EpiBranch call, with one section per package headed by the release it was checked against. It adds recipes for ringbp's asymptomatic offspring (a different mean, or their own offspring distribution), epichains' `percent_immune` and simulist's `contact_distribution` with `prob_infection`, and notes that line lists can be written with CSV.jl. `docs/check_r_mapping.jl` compares the mapping with the latest release of each package.
