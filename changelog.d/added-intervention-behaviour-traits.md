`ModelSpec` now infers, once per intervention type when it is built, whether an intervention is time aware (it defines `intervention_time`), resolves under capacity (it defines `capacity_key` and `resolve_individual!`) discovers actions (it defines `intervention_actions`) and can supply a competing risk (it defines `competing_risk`). The run reads the stored answers instead of the method tables. An intervention written outside the package needs no declaration. `EpiBranch.time_aware`, `resolves_under_capacity`, `discovers_actions` and `has_competing_risk`, with `proposes_actions` that follows from them, are public and can be defined to override an inferred answer.
