`simulate` runs a branching process as daily counts when it has a discrete generation time on whole days, nothing about individuals feeds back on transmission, and the run is bounded by `max_time` alone (`max_cases = nothing`, `max_generations = nothing`). The result is a `CountSimulationState`, an `AbstractSimulationState` that builds its people, and so its line list, when they are first asked for, from a random number stream it holds. `simulate(model, state; max_time)` continues it. A `Poisson` or negative binomial offspring law and `RenewalOffspring` with a vector generation time qualify. Another model opts in by adding a method to `EpiBranch.count_rule`.
