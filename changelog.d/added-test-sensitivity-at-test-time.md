`Isolation`'s `test_sensitivity` accepts a function `(rng, ind, t) -> probability`, drawn once the test time `t` is known, so test positivity can follow the case's within-host load at that time. The asymptomatic cases tutorial now shows onset as a hazard on the load, and how to calibrate a trajectory model to an incubation period and a serial interval, with the parameters those two distributions can and cannot identify.
