`clinical_presentation` now draws an incubation period for every case, asymptomatic ones included, and records separately whether symptoms appear. `incubation_linked_generation_time` and an `Infectiousness` window with `from = :onset` use that time. Infectiousness that follows a shared course relative to onset therefore applies to asymptomatic cases too. `onset_time`, `Isolation` and `date_onset` in `linelist` still use symptomatic onset only. The 5-day fallback in `incubation_linked_generation_time` is removed: it now raises an error for a case with no incubation period.
