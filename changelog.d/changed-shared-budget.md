A `CapacityConstrained` budget is now one pool shared by all groups in every model. Previously `simulate_by_generation` gave each type the whole `budget_per_period`, and a `GroupVaccination` with `group_key = :type` did the same in the individual-based simulation. `simulate_by_generation` now splits the pool between types by population. It also refuses `on_refusal = DeferRefused()`, which it used to ignore, and it, the mixing approximations and `HybridProcess` refuse an intervention they cannot apply in the same words.
