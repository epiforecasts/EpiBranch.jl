`case_classification(probabilities)` and `ct_value(distribution, case_types)` are attribute builders that write `ind.state[:case_type]` (suspected, probable or confirmed) and `ind.state[:ct_value]` (missing for classifications not covered). `linelist` gains both as columns. `linelist(...; anonymised_names = true)` adds a `case_name` column with a stable 16-character hexadecimal code derived from `id`.
