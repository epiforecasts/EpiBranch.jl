Mooncake now stops with a clear error on a `loglikelihood` that has to be estimated by simulation, such as a `ModelSpec` with an intervention, instead of failing inside the simulator. The estimate is noisy and piecewise constant in the model's parameters, so it has no useful gradient: fit it with a sampler that needs only likelihood values, such as `MH()`. The error needs Mooncake loaded, through the new `EpiBranchMooncakeExt` extension.
