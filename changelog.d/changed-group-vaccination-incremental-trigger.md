`GroupVaccination` keeps each group's trigger time and the members still to be offered a dose in the run's `scratch`, and updates them as cases settle. A call used to read every member of each candidate group twice, so a run cost about cases times group size; it now costs time in the members it has not yet dealt with. A trigger that moves earlier puts the group back in the queue, so doses still move to a genuinely earlier trigger as before.
