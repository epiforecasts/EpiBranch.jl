A `CapacityConstrained` budget is now shared by every group in every engine unless it is a `PerGroup`. `simulate_by_generation` used to give each type the whole `budget_per_period`, and a `GroupVaccination` with `group_key = :type` did the same in the individual-based simulation; both now draw on one pool (in `simulate_by_generation`, split between types by population), so a budget per type is written `PerGroup(1 => ..., 2 => ...)`. The engines that read a campaign without simulating individuals (`simulate_by_generation`, the mixing approximations and `HybridProcess`) now refuse an intervention they cannot apply in the same words, and `simulate_by_generation` refuses `on_refusal = DeferRefused()`, which it used to ignore.
