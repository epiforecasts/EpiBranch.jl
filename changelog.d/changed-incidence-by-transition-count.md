`weekly_incidence`, `incidence`, `epicurve` and `end_of_outbreak_inputs` now take `by` as a `TransitionCount` naming the state that places a case, such as `by = TransitionCount(:reporting)`, in place of a `Symbol`. A function `ind -> time` is still accepted. The default is unchanged: a case is placed by its onset time, or by its infection time if it has no onset. `TransitionCount(:onset)` is stricter, as it leaves out cases that never reached onset. `by = :infection` is now `TransitionCount(:infection)`, and any other recorded time `:x_time` is now `TransitionCount(:x)`.
